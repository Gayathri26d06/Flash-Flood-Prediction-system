# ML Service — Flash Flood Risk Prediction (FastAPI + Random Forest)

Prototype ML microservice for the SIH 2026 project. Serves a Random Forest
regression model that estimates a 0-100 flash-flood risk score from
rainfall, soil, terrain and historical-risk features.

## ⚠️ Important disclaimers

- **Training data is synthetic.** No real, labeled flash-flood/landslide
  sensor dataset was available, so `train.py` generates a synthetic dataset
  (`data/generate_synthetic_dataset.py`) using a hand-crafted heuristic. This
  is clearly not real disaster data and must never be presented as such.
- **Lead-time estimates are prototype heuristics only** — not a validated,
  physically modeled, or operationally certified forecast.
- **Confidence** is approximated from agreement across the Random Forest's
  individual trees (inverse-normalized standard deviation), not a
  statistically calibrated probability.

## Setup (Windows / macOS / Linux)

```bash
cd ml-service
pip install -r requirements.txt
```

## Train the model

```bash
python train.py
```

This will:
1. Look for `data/training_data.csv` (a real dataset, if you have one with the
   required columns).
2. If not found, generate and save a synthetic dataset to
   `data/synthetic_training_data.csv`.
3. Train a `RandomForestRegressor`, print MAE / RMSE / R² and feature
   importances.
4. Save the model to `models/flood_model.joblib` and the feature order to
   `models/feature_list.json`.

## Run the API

```bash
uvicorn main:app --reload --port 8000
```

The service reads `PORT` from the environment if set (see `.env.example`),
but `uvicorn --port 8000` on the command line takes precedence for local dev.

## Endpoints

### `GET /health`
```json
{ "status": "ok", "model_loaded": true, "note": "..." }
```

### `POST /predict`
Request body (all fields required, matches `FEATURE_COLUMNS`):
```json
{
  "rainfall_1h": 85,
  "rainfall_3h": 130,
  "rainfall_6h": 180,
  "rainfall_24h": 250,
  "soil_moisture": 82,
  "river_level": 75,
  "humidity": 91,
  "temperature": 24,
  "slope": 31,
  "elevation": 1200,
  "historical_risk": 0.8
}
```

Response:
```json
{
  "risk_score": 86,
  "risk_level": "HIGH",
  "confidence": 0.89,
  "lead_time_minutes": 42
}
```

If the model hasn't been trained yet, `/predict` returns **HTTP 503** with a
message telling you to run `python train.py` first — the Node backend's
error middleware (`mlService.js` + `errorHandler.js`) handles this
gracefully rather than crashing.

## Files

| File                              | Purpose                                              |
|-----------------------------------|-------------------------------------------------------|
| `data/generate_synthetic_dataset.py` | Synthetic training data generator                   |
| `train.py`                         | Full training pipeline                               |
| `predict.py`                       | Model loading + inference logic                      |
| `risk_engine.py`                   | Score→level mapping, prototype lead-time heuristic    |
| `main.py`                          | FastAPI app (`/predict`, `/health`)                   |
| `models/flood_model.joblib`        | Trained model (generated by `train.py`)               |
| `models/feature_list.json`         | Ordered feature names the model expects               |
